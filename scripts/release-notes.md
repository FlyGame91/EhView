## EhView — E-Hentai / ExHentai 桌面客户端

一个本地运行的桌面客户端：搜索、图集浏览、内置阅读器、本地缓存、归档下载、本地库与标签管理。所有数据只保存在本机。

## 这一版包含什么

- **两种联网方式**：代理（http:// / socks5://）或 **HTTP/3 直连（无需代理）**
- 内置阅读器（翻页、三种缩放、全屏、预加载、记住进度、**单页另存**）
- 一键下载原始归档（支持原始文件 / 重新采样）
- 图片本地缓存（看过的图离线可看）+ **按画集打开缓存目录**
- 本地库：自动保存全部标签，支持关键词 + 多标签筛选与排序
- 种子面板（seeds=0 会标红警告）
- 顶栏常驻 Hath / GP / Credit 余额

## 本次修复

| 项 | 说明 |
| --- | --- |
| **搜索慢 15 秒** | 元数据接口 `api.e-hentai.org` 解析到 7 个自建 IP 且全部 SNI 阻断，每次搜索都失败重试 4 轮。改走主站 `/api.php`（同一套接口）后：**15,250ms → 1,005ms**，且 rating / posted 由空变为正常返回 |
| gdata 无冷却 | 接口不可用时 10 分钟内不再重试，避免每次搜索空等 |
| `shell:open` 缺失 | 设置页「打开下载目录 / 缓存目录」按钮调用的 IPC 主进程侧根本没有实现，点了静默失败；已补上 |
| 图片域名被墙 | `s.exhentai.org` / `s.e-hentai.org` 的 SNI 被阻断且不走 CDN，按官方同存储域名 `ehgt.org` 重写 |
| 本地库封面空白 | 早期「cover / thumb」两种字段名并存，已统一为 `cover` 并迁移历史数据 |
| QUIC 状态污染 | 从代理切直连后 persist 分区残留的 QUIC server info 会让连接一直回退 TCP，启动时自动回收 |

## 怎么用

1. 解压 `EhView-{{VERSION}}-win-x64.zip`
2. 运行 `EhView.exe`
3. 设置 → 网络 → 选「直连（HTTP/3，无需代理）」，DoH 填一个**境外**端点（如 `https://doh.cleanbrowsing.org/doh/security-filter/`）→ 点「测速优选」→ 保存 → 点「检测直连」
4. 需要登录态时：账号 → 「打开 Chrome 登录」

> DoH 必须是境外且未被墙的端点。国内阿里/腾讯 DoH 的上游同样被污染，返回的是假 IP —— 这就是「测速优选」要同时判延迟和污染的原因。
