## EhView — E-Hentai / ExHentai 桌面客户端

一个本地运行的桌面客户端：搜索、图集浏览、内置阅读器、本地缓存、归档下载、本地库与标签管理。所有数据只保存在本机。

## 这一版包含什么

- **两种联网方式**：代理（http:// / socks5://）或 **HTTP/3 直连（无需代理）**
- 内置阅读器（翻页、三种缩放、全屏、预加载、记住进度）
- 一键下载原始归档（支持原始文件 / 重新采样）
- 图片本地缓存（看过的图离线可看）+ 可配置缓存目录
- 本地库：自动保存全部标签，支持关键词 + 多标签筛选与排序
- 种子面板（seeds=0 会标红警告）
- 顶栏常驻 Hath / GP / Credit 余额

## 本次修复与改动

| 项 | 说明 |
| --- | --- |
| 新增 HTTP/3 直连 | 设置里可切到「直连（HTTP/3，无需代理）」，走安全 DNS 获取真实解析与 `alpn=h3`，让 Chromium 用 QUIC(UDP 443) 绕过针对 TCP 443 的 SNI 阻断 |

| 修复本地库封面空白 | 早期「cover / thumb」两种字段名并存，导致部分条目封面为空；已统一为 `cover` 并迁移历史数据 |
| 设置页新增自检 | 「检测直连」一键验证 e-hentai / exhentai 连通性 |

## 怎么用

1. 解压 `EhView-{{VERSION}}-win-x64.zip`
2. 运行 `EhView.exe`
3. 设置 → 网络 → 选「直连（HTTP/3，无需代理）」，DoH 填一个**境外**端点（如 `https://doh.cleanbrowsing.org/doh/security-filter/`）→ 保存 → 点「检测直连」
4. 需要登录态时：账号 → 「打开 Chrome 登录」

> DoH 必须是境外且未被墙的端点。国内阿里/腾讯 DoH 的上游同样被污染，返回的是假 IP，填了等于没填。
