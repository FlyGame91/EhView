# EhView

E-Hentai / ExHentai 的桌面客户端（Electron + React），把常用的浏览、阅读、下载、收藏整理到一个窗口里，并补上原站在这些环节上缺的功能。

## 它解决什么

| 原站的痛点 | 这里的做法 |
| --- | --- |
| 多页查看器里小图不占满屏、长图看不全 | 内置阅读器：三种缩放（自适应 / 适应高度 / 适应宽度）、连续滚动、全屏、键盘与鼠标区域翻页、前后页预载 |
| 打包下载要先等生成链接，再手动下载 | 详情页一键下载：自动走完归档生成流程，直接落到你设定的目录 |
| 种子 seeds=0 没有提示 | 种子面板解析每个种子的做种/下载数，无人做种时标红提示 |
| 看过的图不在本地 | 本地图片缓存：所有图片经由缓存协议加载，看过的离线也能看；目录可改、可清理、有容量上限 |
| 站点收藏不能按标签检索 | 本地库：收藏时自动保存全部标签，支持关键词 + 多标签组合筛选与排序 |
| 缺少代理与账户信息 | 支持 http / socks5 代理；顶栏常驻 Hath / GP / Credit 余额 |
| 未登录也在调接口 | 登录后才启用收藏、归档、余额等需要鉴权的功能；未登录只用公开接口 |

## 界面

- **搜索**：关键词 / 标签搜索，分类筛选（含排除与「只看这个」三态），无限滚动
- **详情**：标签、页数、文件大小、种子、一键下载、归档花费、预览缩略图
- **阅读器**：左侧缩略图导航、自适应缩放、预载、断点续读
- **本地库**：标签索引与组合检索
- **站点收藏**：无限滚动，与站点同步
- **历史**：浏览记录，与图片缓存容量共用上限
- **下载**：网格卡片，显示封面、实时进度与速度

## 环境要求

- Node.js 20+
- Windows（打包脚本按 Windows 编写；主进程代码本身跨平台）

## 从源码运行

```bash
npm install
npm run build      # 构建前端到 dist/
npm start          # 启动 Electron
```

开发模式（前端热更新）：

```bash
npm run dev        # 另开一个终端
npm start
```

## 打包

```bash
npm run build
# 然后把 electron/ 、dist/ 、package.json 与生产依赖一起放进 Electron 的 resources/app/ 目录
```

## 登录

ExHentai 的多数接口要求登录。软件不会在未登录状态下调用需要鉴权的接口。

1. 打开「设置 → 账号」，点「打开 Chrome 登录」。
2. 在弹出的独立 Chrome 窗口里完成登录（Cloudflare 验证由真实浏览器自然通过）。
3. 登录后同一窗口会打开 `https://exhentai.org/`，等它跳转完成（这一步会取得 ExHentai 所需的 cookie）。
4. 回到软件点「检测登录状态」，软件会读取并解密登录 Cookie 后保存。
5. 自动读取失败时，可用「手动导入 Cookie」粘贴 `ipb_member_id=...; ipb_pass_hash=...`。

> 软件使用**独立**的浏览器配置目录，不会读写你日常浏览器的登录数据。

## 代理

设置页可填 `http://127.0.0.1:10809` 或 `socks5://127.0.0.1:10808` 之类的地址，主进程与下载层都会走同一个代理。

## 目录结构

```
electron/          主进程：网络、页面解析、缓存、下载、Cookie、配置
  lib/eh.js        站点接口封装
  lib/parser.js    HTML 解析
  lib/cache.js     图片缓存与回收站
  lib/download.js  下载队列
  lib/history.js   浏览历史
  lib/library.js   本地库与标签索引
src/               渲染进程（React）
  pages/           各页面
  components/      卡片等通用组件
  lib/             跨页面共享状态
```
